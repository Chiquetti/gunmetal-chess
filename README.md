# Gunmetal Chess

Chess in the browser with gun-shaped pieces. Play the computer (Easy, Medium, Hard) or study famous master games move by move.

- Engine: [Stockfish](https://github.com/official-stockfish/Stockfish) (GPL-3.0), WebAssembly build from the `stockfish` npm package. License in `lib/STOCKFISH-LICENSE-GPL3.txt`.
- Rules: [chess.js](https://github.com/jhlywa/chess.js) (BSD-2-Clause).
